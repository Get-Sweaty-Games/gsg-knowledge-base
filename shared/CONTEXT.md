# Shared

Cross-department knowledge that would otherwise force two departments to reference each
other — a backend-Unity wire contract, a shared brand asset, an org-wide decision.

## One-Way Rule

Departments may reference `shared/docs/`. `shared/docs/` never references back into a
specific department — department-specific detail stays in that department's own doc with
a pointer to the shared contract.

## What's Here

| Location | Contains |
|---|---|
| `docs/CONTEXT.md` | Index of every canonical doc here, and what each covers |
| `updates.md` | Append-only recent-additions log — read for a quick catch-up |

## When Something Belongs Here Instead

Route to `shared/` when a drop-in genuinely needs multiple departments to see the same
document, not when it merely mentions another department in passing.
